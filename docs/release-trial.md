# Sealed release trial preregistration

Register this plan before any sealed case is opened. The study measures whether providing the CLI improves what a fresh successor can conclude from committed work, within an acceptable burden. The six-family A-gate pilot provides the planning variance. Qualification runs, development cases and pilot cases remain outside the sealed sample. [Pilot result](a-gate.md) · [Planning data](../training/a-gate/results.json)

## Primary outcome and decision

Use the proportion of warranted rubric items present in the fresh successor's normalized four-field answer. Freeze item definitions and allowed alternatives per case family before scoring. In each case, compute the difference between CLI available and Markdown on the same variant and model. Average variants and models within an underlying family. Weight the independent families equally, with equal allocation to the four domains.

The single release criterion is a useful accuracy gain within a wall-time budget. Require the lower endpoint of the two-sided 95% case-clustered interval to reach **+10 percentage points** and the CLI arm's mean total investigator-plus-successor time to be **at most 1.25 times** the notes arm mean. Report both quantities and their paired intervals. The record must reconcile all assignments. Report uncertainty and withhold the improvement claim when either threshold is unmet or the evidence is incomplete.

Report false promotions and missed warranted answers with denominators, including interrupted work. These are diagnostic outcomes alongside the one acceptance rule. Report raw and metered token totals, shell calls, preparation, and discovery and evidence bytes. Separate lookup probes from this primary test. State the bound for any class with zero observed errors using the independent family count. Do not generalize tool availability effects to structured-record mechanisms without evidence of canonical use.

## Allocation and sample size

Enroll **84 independent families**, 21 each for intermittent debugging, p99 regression measurement, source research and architecture choice. Each family has an original variant and a prespecified missing-evidence or cosmetic twin. Keep those twin types as evenly distributed within each domain as the odd count allows. Run both variants in both arms for each of two pinned agent families or hosts. Each model makes one investigator and one fresh successor attempt per assignment. This gives two independent model observations for each variant and arm, with no within-model repeats in the primary sample. The schedule contains 672 paired-arm assignments in total, or 1,344 investigator and successor sessions.

The pilot estimate of between-family variance was 0.02375 on the proportion scale, based on six families. For planning, the approximate one-sided 95% normal-model upper variance is `5 × 0.02375 / 1.145476226 = 0.10367`, where 1.145476226 is the lower 5% chi-square quantile on five degrees of freedom. Size for 80% planning power at a true gain of 0.20 relative to the minimum useful gain of 0.10. The normal approximation gives `(1.959964 + 0.841621)² × 0.10367 / (0.20 − 0.10)² = 81.37` families. Round up to a multiple of four. This is an uncertainty-aware planning approximation. Six cases from two domains cannot establish the future variance or guarantee power, and power will be lower for gains near the decision threshold.

## Execution and analysis

Have someone who did not work on onboarding or blindspot rules author the sealed families. Register them under the sealed split, keep all twins in the same family, and hold keys beyond participant access. Commit the trial protocol hash first. Before assigning a run, freeze the release-candidate binary, hosted or local tool versions, agent model identifiers, inference settings, budgets, prompts and seeded counterbalanced schedule. Give both arms the same sources, tools, budgets and review checkpoint, with the CLI added only to the treatment arm. Separate sessions and block any access to previous transcripts, evaluator files and assignment identities.

Grade normalized answers with the arm map withheld and preserve every planned assignment. A timeout or exhausted budget counts as an attempted assignment. Missing answers miss all warranted items. A technical deviation documented as invalid must use the frozen invalidation policy and report the original attempt. Report the paired point estimate and intervals from 10,000 family bootstrap resamples stratified by domain, with seed `872308`. Report each domain and model, both twin types, and the fraction of variants for which both independent model observations meet all warranted items without an unwarranted promotion. Report the analogous paired wall-time interval and per-arm cost counters. Publish the full manifest, deviations, assignment-blinded grades and the analysis before interpreting a release claim.
