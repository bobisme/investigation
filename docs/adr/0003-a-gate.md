# ADR 0003: Milestone A pilot decision rule

Status: accepted before pilot runs; 2026-11-22.

Milestone A delivers two working vertical slices. The separate A-gate runs before W07 and before freezing the wider catalog as `inv.command.v1`. Compare `inv` plus ordinary file/search tools against plain Markdown notes plus those same tools, using paired pilot-split debugging and architecture-choice case families. Use at least two agent families or hosts, matched budgets and sources, counterbalanced order, pinned versions and independent sessions. An unfamiliar investigator brings a local source and hands off to a fresh successor. Insert a new hard criterion between review and acceptance; ask the successor what changed and whether another measurement would affect the choice. Grade normalized, arm-blinded successor answers against a prewritten rubric; report false promotions, successor accuracy, missed warranted answers and cost.

Before the pilot, freeze the expected successor answer items and opportunities for unwarranted promotion for each case. Score each item against the blinded rubric and use the same denominators for both arms. Count any claim presented with a disposition beyond that warranted by the fixture as a false promotion. Calculate each metric within paired cases first, then average the paired differences with equal case weights. A strict reduction in false promotions or a strict increase in successor accuracy counts as improvement on that measure. Report ties and mixed directions explicitly. These are directional pilot criteria, not significance tests.

If neither measure improves, identify each record type the case rubric offered an opportunity to use. Count a type as ignored when the investigator omits it at that opportunity or the successor fails to retrieve its relevant content. Count it as misused when the record is substantively empty, misclassified, unsupported, or used to make a materially unwarranted inference. Use committed journals and blinded successor answers to substantiate the classification. Cut or merge the types that were ignored or misused before continuing to W07. If there is no defensible simplification or the pilot data are inadequate, stop and reconsider the design while the gate stays open. Record evidence, changes and rationale in a new ADR, rerun affected checks, and resolve the gate before freezing the catalog. A pilot cannot establish a general improvement claim; report uncertainty, paired results, per-arm costs and between-case variability. If observations do not allow a defensible comparison, the gate is unresolved. Preregister the later release trial's primary outcome, minimum useful difference, burden limit and sample size before opening sealed cases; §20.5 governs that separate release decision.
