# 0005. Milestone A qualification boundaries

Accepted for the `v0-alpha` implementation on 2026-11-22.

- Local file capture opens a descriptor within a configured import root on Linux and bounds each retained input to 64 MiB. This keeps the first import path bounded while streaming and archive support remain in later work.
- A causal promotion qualifies one named factor with a retained baseline, treatment, and reversal under a matching recorded environment. Other factors can remain candidates. The tool records the producer's attributed account and checks its retained evidence.
- A comparison can state a named statistic and sample count. The alpha observation contract cannot attest these separately, so the engine keeps those hard checks conditional and excludes them from certain Pareto rankings. Later promotion requires typed evidence for the statistic and sample.
- Tests qualify specific application publication checkpoints, real multi-process locking, the in-memory crash model, and a mounted LazyFS cache loss. Physical-device power loss and clean-machine archive restore remain separate qualification.
- Recovery reclaims elapsed journal-publication temporaries under the commit lock. Import staging can be in progress outside that lock. Retention and reclamation of that staging require a separate ownership protocol.
- The paired successor study and stabilization of the versioned schema follow the smoke proofs.

See the [worked proof](../milestone-a.md) and [filesystem support matrix](../support-matrix.md) for commands and observed limits.
