# A-gate pilot cases

The registry defines thirteen case variants across six substantive families and one lookup. Each substantive family starts with identical source bytes across its twins. Its variants differ only in the evidence delivered after review. A missing-evidence twin drops a decisive measurement. A cosmetic twin changes wording or a name while preserving what the evidence supports. The two models repeat each case in both arms. Analysis clusters results by the six substantive families and reports the lookup separately.

The pilot cases use different situations from the Milestone A development examples. Three independent families per substantive domain permit an exploratory estimate of between-family variability while allowing both local models to run every variant in both arms. This small pilot cannot establish a release claim. Participant directories receive only their own initial source and optional review-stage update.
