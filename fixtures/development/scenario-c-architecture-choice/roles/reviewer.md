# Reviewer role

Verify the baseline's zero-loss and 300-second recovery requirement against the
specified abrupt process or single-host stop. Check whether every option has
evidence for both components; a missing recovery-time measurement is `unknown`,
not a pass. Recompute the p99 values from the retained samples and check units,
sample counts, warmup and environment.

The cost estimate inherits an unverified traffic volume. The source calling an
option “best” is an author's preference. In `strict-threshold/`, only the hard
criterion changes; dependent comparisons and the accepted decision need review
while the original evidence remains available and unchanged.
