# Reviewer role

Check source digests before reviewing selectors. The primary trace reports a
28-second connection hold across an asynchronous callback; the control shares
the build and workload. Verify the pool samples cover the same monotonic
interval. The method runs toggle release-before-await on and back off.

Do not use the broken-clock trace for event ordering or negative evidence. In
the `different-build-trap` variant, the scheduler-only test changes the build;
it cannot refute the scheduler hypothesis for the baseline build. Require a
bounded or inconclusive conclusion and a visible comparability limitation.
